# SmartCart - E-Commerce Discount & Delivery System

SmartCart is a React-based e-commerce web application.

## Features
- Display a list of products
- Product categories and prices
- Special shopping offers
- 10% discount on orders above ₹1,000
- Free delivery on orders above ₹1,000
- Responsive design

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## How to Run

1. Clone the repository.
2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev
